# V19 TEST — publication GitHub Pages

Cette branche est réservée à la prévisualisation de l'application Renforcement musculaire Cattenom V19.

- Hébergement : GitHub Pages via `.github/workflows/deploy-v19-test-pages.yml`.
- Backend : projet Supabase **TEST** `uqyvfkjgitufaxmswjzv`.
- Capacité visée : 20 places réservées et 10 en liste d'attente.
- Notifications OneSignal : reportées à la bascule V19.
- V18 Production : ne pas modifier, fusionner ou déployer depuis cette branche.

## Mise en ligne

Dans **Settings > Pages > Build and deployment**, sélectionner **GitHub Actions**.
Chaque commit sur cette branche déclenche alors le workflow de publication.
L'URL Pages est fournie dans le résultat du workflow, une fois celui-ci réussi.

## Vérifications avant utilisation réelle

Contrôler l'ouverture de l'interface, la connexion Supabase TEST, les inscriptions et annulations, les règles de capacité et les droits administrateur. La présence du site en ligne ne prouve pas à elle seule la validation de ces fonctions.
